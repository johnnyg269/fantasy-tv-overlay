# Source and asset provenance

The Samsung native renderer originates from the generic EFL overlay probe in [chris-ritsen/samsung-tv-root](https://github.com/chris-ritsen/samsung-tv-root), released under the Unlicense. The project retains that license and documents the pinned external SDK separately. The Samsung renderer additions, companion, feed backend, Android implementation, tests, guides and original UI assets in this repository are released under the same license unless a file states otherwise.

Inter and Bebas Neue are redistributed under the SIL Open Font License 1.1; their license texts accompany the fonts. Generated button and gradient assets are original project UI artwork. The repository preview is an original synthetic illustration, with fictional managers and scores. It is not a photograph, broadcast capture, or proof of any device result.

Quiet Tizen informed the original setup and font loading workflow. See [jss8649/quiet-tizen](https://github.com/jss8649/quiet-tizen) for that independent project and its own licensing. No Quiet Home launcher, user configuration or private TV framework binaries are included.

The ESPN adapter is an independent implementation informed by public endpoint behavior and the upstream [espn-api](https://github.com/cwendt94/espn-api) reference shape. Sleeper's adapter follows [its official API documentation](https://docs.sleeper.com/). No upstream account responses or private data fixtures are redistributed.

Samsung/EFL/.NET device libraries, Android SDK, root SDK releases, Apple TV credentials and third-party service accounts are external prerequisites, not assets licensed or bundled here. No affiliation or endorsement by the device or fantasy providers is implied.
